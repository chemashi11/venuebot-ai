# Color Palette:

Primary: Deep Espresso Brown (#3E2723) - Gives a premium coffee shop vibe.

Secondary: Warm Amber/Gold (#FFB300) - For buttons and highlights.

Background: Soft Cream/Off-white (#FFF8E1) - Easy on the eyes.

Study Zone Accent: Sage Green (#81C784) - For a calm, focused feel.

Alert/Error: Soft Red (#E57373).

# Typography: 
Playfair Display (for headings - fancy) and Inter or Roboto (for body text - clean).

# Animations (Little bit fancy):

When a user books a table, the confirmation card should slide up and fade in.

Buttons should have a subtle "ripple" effect.

The AI Chat interface should have a "typing" animation (three bouncing dots) while the agent is thinking.
